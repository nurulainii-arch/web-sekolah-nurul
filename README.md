# Web Sekolah - Projek UKK

Projek ini adalah hasil Ujian Kompetensi Keahlian (UKK) dengan tema **Website Sekolah** menggunakan framework **Laravel**.

## 🚀 Fitur Utama
- Halaman profil sekolah
- Informasi guru dan siswa
- Berita dan pengumuman
- Manajemen data berbasis database MySQL

## 🛠️ Teknologi yang digunakan
- [Laravel](https://laravel.com/) 10
- PHP 8.x
- MySQL
- Bootstrap / Tailwind (opsional sesuai projek)
- GitHub untuk version control
